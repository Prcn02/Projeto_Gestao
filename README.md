# Projeto_Gestao 
Projeto unisuam de gestão de projetos 

<img width="1024" height="768" alt="Gray Simple Organization Chart Graph" src="https://github.com/user-attachments/assets/fb566de4-9470-428d-844b-712d44f6ab31" />

Durante o período de desenvolvimento, os integrantes do projeto realizaram o levantamento de requisitos, a análise de negócio e a execução das atividades de acordo com suas respectivas responsabilidades.
As entregas foram organizadas e disponibilizadas neste repositório por meio de arquivos individuais, refletindo a contribuição de cada integrante nas diferentes áreas do sistema.
A estrutura do projeto foi definida de forma colaborativa, garantindo o alinhamento entre as áreas e a integração das funcionalidades propostas.
